# Life Companion Hub

أريد تنفيذ جميع التعديلات التالية دفعة واحدة في تطبيق «سندك في الحياة»، مع الحفاظ على التصميم الحالي والألوان العربية واتجاه RTL، وعدم حذف أو تغيير أي ميزة تعمل حاليًا:

1. إصلاح صفحة البحث

زر «البحث» في شريط التنقل السفلي حاليًا يفتح صفحة 404.

أنشئ صفحة بحث صحيحة على المسار /search إذا لم تكن موجودة.

اربط زر البحث بها.

يجب أن يستطيع المستخدم البحث عن مقدم خدمة أو طبيب أو صيدلية أو مستشفى أو عقار أو خدمة توصيل.

2. إضافة صفحة التقييم

إضافة صفحة يستطيع المستخدم من خلالها تقييم مقدم الخدمة بعد التعامل معه.

التقييم من 1 إلى 5 نجوم.

إضافة تعليق اختياري.

عرض متوسط التقييم على بطاقة مقدم الخدمة والطبيب والصيدلية والمستشفى وباقي مقدمي الخدمات.

تحديث متوسط التقييم بعد إضافة تقييم جديد.

3. إضافة صفحة الاشتراك والدفع لمقدمي الخدمات الأسعار الشهرية:

الأطباء: 20,000 جنيه سوداني.

الصيدليات: 20,000 جنيه.

المستشفيات: 20,000 جنيه.

البيع: 20,000 جنيه.

مقدمو الخدمات: 20,000 جنيه.

التوصيل «ركشة – موتر – توكتوك»: 10,000 جنيه.

يكون الشهر الأول مجانيًا لمقدم الخدمة، وبعد انتهاء الفترة المجانية يبدأ الاشتراك الشهري.

طرق الدفع:

بنكك

فوري

أوكاش

بعد الدفع:

يستطيع مقدم الخدمة رفع صورة إشعار الدفع.

يظهر زر لإرسال/تأكيد إشعار الدفع للإدارة.

رقم الإدارة وواتساب الإشعارات: 0913032542.

لا تخترع أرقام حسابات دفع غير موجودة.

4. قسم الصيدليات عند اختيار الصيدلية تظهر:

اسم الصيدلية.

اسم موظف الاستقبال.

رقم هاتف موظف الاستقبال.

زر اتصال.

زر واتساب عند توفر الرقم.

5. قسم السكن والعقارات أضف خيارين:

بيع.

إيجار.

بعد اختيار بيع أو إيجار يظهر نوع العقار:

منزل.

مكتب.

ثم تظهر تفاصيل العقار بصورة واضحة.

6. قسم التوصيل نوع التوصيل:

موتر.

ركشة.

توكتوك.

ويظهر:

اسم السائق.

رقم التواصل.

زر اتصال.

زر واتساب.

7. المستخدم العادي المستخدم الذي يبحث أو يطلب خدمة لا يجب إجباره على إنشاء حساب أو إدخال بيانات شخصية. يجب أن يستطيع مباشرة:

البحث.

مشاهدة مقدم الخدمة.

الاتصال.

واتساب.

طلب الخدمة.

الحجز عند توفره.

الإضافة للمفضلة.

التقييم.

الإبلاغ.

8. شريط التنقل تأكد أن جميع الأزرار تعمل ولا يوجد أي رابط يؤدي إلى 404، خصوصًا:

الرئيسية.

البحث.

الخدمات.

الأطباء.

المفضلة.

9. مهم جدًا

نفّذ جميع هذه التعديلات في تعديل واحد.

لا تغيّر التصميم الحالي للصفحة الرئيسية.

لا تحذف البيانات أو البطاقات الموجودة.

حافظ على الألوان والخطوط وطريقة عرض البطاقات الحالية.

اختبر جميع الروابط والصفحات بعد التنفيذ وتأكد من عدم وجود صفحات 404.

اجعل التطبيق مناسبًا للموبايل بالكامل.

هذا يجمع البحث + التقييم + الدفع + الأسعار + الصيدليات + العقارات + التوصيل + إصلاح التنقل في تعديل واحد.
